# 결정 기록

되돌리기 어렵거나 다음 작업이 기대는 결정을 남긴다. 한 결정에 한 파일을 쓰고 번호를 이어 붙인다. 결정을 바꿀 때는 이전 파일을 지우지 않고 '대체됨'으로 표시한 뒤 새 파일을 만든다.

형식: 상태(제안, 채택, 대체됨), 날짜, 맥락, 결정, 결과, 검토한 다른 길.
