# 0003. 배포 방식과 맡겨진 결정

- 상태: 채택
- 날짜: 2026-10-31
- 요청: 열린 결정 질문에 사용자가 "그냥 싹 다 배포해줘. 태블릿은 갤럭시탭인데 아이패드도 되면 좋지. 브랜치 올려도 돼."라고 답했다.

## 결정

1. 배포(열린 결정 2): 검증을 마친 변경은 단계마다 바로 main에 올려 공개한다. 단원이 끝날 때까지 기다리지 않는다. 수업 시간에는 배포하지 않는다는 규칙(AGENTS.md 8)은 그대로다.
2. 브랜치: 작업 브랜치를 원격에 올린다. GitHub CI가 통과한 뒤 main을 그 브랜치로 앞당겨 합친다(fast-forward).
3. 태블릿 종류(결정 0002의 남은 질문): 갤럭시 탭(안드로이드, Chromium 계열 브라우저)이 주 기기다. 아이패드(Safari)에서도 쓸 수 있게 한다.
4. 답하지 않은 열린 결정 3·4는 '그냥 싹 다'로 맡긴 것으로 보고 추천안으로 진행한다. 되돌리기 쉬운 방식으로 하고, 사용자가 다르게 정하면 따른다.
   - 4(소음 주제): '준비 중'을 유지하고, 알림창을 비활성 표시와 화면 안 안내 문구로 바꾼다. 내용과 링크는 지우지 않는다(1단계에서 적용).
   - 3(기록장 구조): 2단계에서 '기록 하나와 자료 패널'로 바꾼다.
5. 열린 결정 5(학교·학급·교사 실명·수업 일시가 든 지도안)는 사용자가 준 원본 문서를 고치는 일이라 명시적인 답 없이는 하지 않는다. 지금의 공개 상태를 그대로 둔다.
6. 열린 결정 6~10은 추천안이 '지금 구조를 유지한다'라서 바꿀 것이 없다. 정식 답을 받을 때까지 계획에 열어 둔다.

## 결과

- 하네스(커밋 `00d7e08`)를 이 방식으로 처음 배포했다. CI 통과, Pages 빌드 완료.
- 검증 크기에 갤럭시 탭 화면(세로 800×1200, 가로 1280×720, 주소창을 뺀 대략의 크기)을 더했다.

## 검토한 다른 길

- 남은 결정을 모두 다시 묻기: 사용자가 진행을 원해 택하지 않았다. 대신 맡긴 범위와 하지 않은 일을 이 문서와 보고에 밝힌다.
