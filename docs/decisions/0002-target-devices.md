# 0002. 주 기기는 태블릿과 PC

- 상태: 채택
- 날짜: 2026-10-31
- 요청: 개편 계획의 열린 결정 1(학생이 주로 쓰는 기기)에 사용자가 "태블릿이나 pc"라고 답했다.

## 결정

1. 학생의 주 기기는 태블릿과 PC다. 화면 기준과 측정은 세로 태블릿(폭 600~834px), 가로 태블릿(1000~1366px), PC(1280~1920px)를 1순위로 본다.
2. 휴대폰은 주 기기가 아니다. 활동지 QR로 열었을 때 가로로 넘치거나 겹치지 않는지만 확인한다.
3. 태블릿에서는 손가락과 화면 키보드로 쓴다고 보고 DESIGN.md 4절의 터치 기준을 따른다.
4. 기록장의 옆 자료 패널은 폭 1024px 이상에서 쓰고, 그보다 좁은 세로 태블릿에서는 기록 위에 덮는 시트로 연다. 기록장 구조 변경(결정 3)을 정하면 그때 적용한다.

## 아직 모르는 것

- 한 사람이 한 기기를 쓰는지, 모둠이 한 기기를 함께 보는지. 정해지기 전에는 둘 다 되게 만든다.
- 태블릿 종류(아이패드, 안드로이드 태블릿)와 브라우저. ego-browser는 Chromium이라 아이패드 Safari 동작(파일 저장, 화면 키보드)은 실제 기기로 따로 확인해야 한다.
  - 후속(같은 날): 갤럭시 탭이 주 기기이고 아이패드도 되면 좋다고 답을 받았다([0003](0003-deploy-and-delegated-decisions.md)).

## 결과

- 측정 목표와 검증 크기를 태블릿과 PC 기준으로 바꿨다(개편 계획, DESIGN.md 1·4·6절, `discuss-verify`, AGENTS.md).
- 태블릿 크기에서 다시 재 보니 지금 기본 배치는 폭 1120px 이하에서 자료와 기록을 위아래로 쌓아 쓰기 칸을 1.4~1.9화면 아래로 민다([태블릿·PC 측정](../audits/2026-10-31-tablet-pc.md)).

## 검토한 다른 길

- 휴대폰까지 1순위로 두기: 세 가지 폭을 모두 맞추느라 태블릿 배치가 타협된다. 사용자 답에 휴대폰이 없어 택하지 않았다.
