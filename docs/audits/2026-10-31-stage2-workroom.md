# 2단계 기록장 측정 (2026-10-31)

개편 2단계(기록 하나와 자료 패널)를 마친 뒤 [태블릿·PC 측정](2026-10-31-tablet-pc.md)과 같은 방법으로 다시 쟀다. 시점 기록이라 나중에 고치지 않는다.

## 방법

- 브랜치 `stage2-workroom-layout`의 사이트 파일, ego-browser(Chromium) 화면 흉내와 터치 흉내. 기본 진입 주소 `workroom.html?view=both#personal`과 `#group`, 세션 저장소를 비운 첫 방문.
- 실제 기기와 아이패드 Safari는 확인하지 않았다. 화면 캡처와 원본 수치는 이 Mac의 `.qa/stage2-2026-10-31/`에 있다(git 제외).

## 동작

- 옆 패널: 닫기·열기, 새로고침 뒤 닫힌 상태 유지, 연 뒤 초점이 '자료 닫기'로, 닫은 뒤 '자료 보기'로 간다.
- 시트(세로 태블릿): 화면 전체를 덮고, 뒤쪽 기록은 `inert`, 페이지 스크롤은 막힌다. Esc로 닫히고 초점이 '자료 보기'로 돌아간다.
- 회전: 800·820·768px에서 닫히고 1280·1180·1024px에서 다시 열린다.
- 자료 고르기와 위치: '가상 인물 인터뷰'를 고르면 패널 제목, 눌림 표시, iframe 주소가 바뀌고, 자료 안 위치(1,200px)가 패널을 닫았다 열어도 돌아온다. 자료 안에서 기록장 활동 링크(`discussion-activity`)를 누르면 모둠 활동으로 바뀐다. 패널 안에 기록장이 다시 뜨지 않는다.
- 단계 표시: 스크롤에 따라 지금 단계에 `aria-current="step"`이 붙고, 맨 아래에서는 마지막 단계다. 단계 링크를 누르면 제목이 고정 막대 아래에 온다.
- 기록: 입력 뒤 새로고침 복원, 개인·모둠 전환 뒤 보존, 기록 파일 내려받기(v4)와 불러오기(확인 뒤 교체), 다른 창 수정 경고와 경고 안 내려받기, 모둠 1단계 입력이 2단계 요약에 바로 반영.
- 공유 카드: 이미지에 들어갈 글이 버튼 위에 보이고, 1920×1080 이미지와 파일 이름 `개인의견-근거.png`, 개인은 1~6모둠 패들렛, 모둠은 학급 패들렛 하나.
- 인쇄 화면에서 자료 패널, 고정 막대, 안내 줄, 상태 줄이 숨는다.
