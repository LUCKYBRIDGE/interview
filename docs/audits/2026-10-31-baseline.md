## 요약

1. 기록장의 첫 입력란이 첫 화면 밖에 있다. 휴대폰 폭의 개인 활동은 1,659px, 모둠 활동은 2,139px 아래에 있다. 그 위에 머리글, 활동 전환, 안내, 화면 구성, 자료 패널이 먼저 나온다.
2. 기록장 배치가 17가지(한 화면 4, 분할 13)로 늘었다. 배치를 고르는 선택 상자가 3개이고, 10-29의 커밋 40개 대부분이 이 배치의 충돌을 고친 것이다. 기록장이 자기 안에 iframe으로 다시 뜨는 경로가 있다.
3. 자료 페이지는 길을 찾기 어렵다. 홈에 내비게이션이 여러 겹(머리글 버튼, 안내 상자, 주제 카드, 활동 버튼, 공통 자료 버튼, 단계 카드)이고, 정작 탭 메뉴는 접기 안에 숨어 있다. 홈 패널 길이는 1440px 폭에서 10,363px, 390px 폭에서 19,734px다.
4. 글자와 누름 영역이 작다. 13px보다 작은 글자 선언이 83개, 자료 홈의 조작 요소 255개 중 189개가 44px보다 낮다(1440px).
5. 화면에 없는 기능과 숨긴 단계를 가리키는 문구가 남아 있다('기록만·탐구만·함께 보기', '활동 공간', 'STEP 1·3·3').
6. 통계 카드 15개 중 기관 이름이 보이는 카드와 확인 날짜가 있는 카드가 하나도 없다. '원자료 확인' 링크 15개 중 10개는 기사나 보고서다.
7. 공개 다운로드인 지도안 4개 파일에 학교, 학급, 교사 실명, 수업 일시가 들어 있다.
8. 문서가 현재 상태와 다르다(배포하지 않았다는 주장, 옛 화면 이름, 저장소 밖 경로). 수업 문서 원본과 생성 스크립트가 형제 작업 공간 discussion과 이 저장소로 나뉘었고, discussion의 동기화 스크립트는 옛 클론을 가리킨다.

### 배치와 상태 (`assets/explore-pane.mjs`, `workroom.html`)

- 화면 구성 버튼(한 화면, 분할 화면), 선택 상자 3개(한 화면에 표시할 내용, 왼쪽, 오른쪽), 비율 초기화, 분할선, 탐구 닫기, 별도 창 보기가 모두 배치를 바꾼다. 개인 활동 편집을 고르는 길이 4곳이다.
- 같은 내용을 양쪽에 고르면 나중에 고른 쪽이 이기고 다른 쪽은 말없이 빈 상태가 된다(36~42, 60). 빈 상태에는 고르기 버튼이 없다.
- 왼쪽에서 개인·모둠 편집을 고르면 `workroom.html?panel=1`을 iframe으로 띄운다. 그 안에서 머리글과 화면 구성까지 다시 그려진다. CHECKLIST의 '중첩 활동 화면 없음' 확인과 맞지 않는다.
- 코드상: iframe 편집기가 부모와 같은 sessionStorage 키를 덮어써서 새로고침하면 부모 배치가 바뀐다(80, 254~256). 같은 활동의 편집기가 부모(숨김)와 iframe에 동시에 살아 있으면 storage 이벤트로 자동 저장이 멈추고 '다른 창에서 바뀌었습니다' 경고가 뜰 수 있다(`assets/workroom.mjs` 296~304).
- 코드상: 오른쪽 자료 iframe 안의 활동 링크는 아무 일도 하지 않는다(메시지를 왼쪽 iframe에서만 받음, 240). 한 화면 select의 '개인활동 기록 보기'는 실제로 편집 화면을 연다(197).
- 기본 진입이 `?view=both`라서 새로고침할 때마다 분할 화면과 자료 홈 맨 위로 돌아간다(81).

### 흐름과 상태 표시 (`assets/workroom.mjs`)

- 도구 결과, 최종 확인 해제 알림, 불러오기 오류가 접힌 '기록 파일과 인쇄' 안의 상태 줄에 나와 접혀 있으면 보이지 않는다(286).
- 저장 충돌 경고는 '기록 파일을 먼저 보관하세요'라고 하지만 내려받기 버튼은 접힌 곳에 있다.
- 모둠 최종 확인 체크박스가 접힌 '발표 전에 더 살펴보기' 안에 있다(224~225).
- 모둠 2단계의 의견 요약은 다시 그릴 때만 바뀌고 1단계 입력을 바로 반영하지 않는다(208~218).
- 개인 의견 이미지에는 화면에 입력란이 없는 이전 `evidence` 값도 들어간다(`assets/opinion-image.mjs` 41).
- 글 파일·인쇄 출력의 단계 번호가 화면과 다르다. 개인은 5단계, 모둠은 1·3·4로 나온다(`assets/workroom-state.mjs` 124~144).
- 단계 표시에 지금 단계 표시(`aria-current`)가 없다. 학생에게 차시 번호(9~10차시 등)가 보인다.

### 스타일

- 같은 선택자 다시 정의 57곳(workroom.css와 redesign 44, explore-pane.css와 redesign 13), 기록장 페이지 `!important` 25개, 인라인 style 2개.
- 중단점이 1120, 1050, 700, 650, 640, 520px로 섞여 있다. JS는 1120px, 문서는 1050px라고 적는다.
- 선택 상태 색이 두 가지다(활동 전환은 민트, 화면 구성은 짙은 초록).
- 쓰지 않는 코드: 숨은 '참고 화면' 버튼, 늘 빈 안내 줄, `left-personal.mjs` 패널 전체, 'explore' 모드 값, 화면에 붙지 않는 전체 의견 링크.

- 같은 대상을 여러 이름으로 부른다: 가상 인물·AI 인물·시민·인터뷰 시민, 탐색·탐구·조사, 개인활동·개인 활동, 모둠토의·모둠 토의, 인도·보도·보행로·통행로, 어르신·노인·고령자, 이동 약자·교통약자. 사이트 이름도 놀토의와 '우리 동네 토의 탐구실'이 섞여 있다(135, 299).

## 5. 공개 범위와 개인정보

- Pages가 main 루트를 공개하므로 작업 문서, 스크립트, 테스트, 쓰지 않는 자산 12개(수업 삽화 2.5MB 포함)도 공개된다. README가 아닌 Markdown은 HTML로도 공개된다.
