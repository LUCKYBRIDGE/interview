# 23인의 AI 인터뷰

초등학교 5학년 국어 토의 수업을 위한 Gemini Gem 링크 모음 웹페이지입니다.

## 기능
- 23개 인터뷰 카드 및 번호 검색
- 무작위 인터뷰 선택(미방문 우선)
- 브라우저 로컬 저장소에 방문 기록 저장 및 초기화
- 모바일·태블릿·데스크톱 대응
- Gemini 링크 새 탭 열기

## 배포 (GitHub Pages)
1. GitHub 리포지토리 **Settings → Pages** 이동
2. **Build and deployment → Source: Deploy from a branch** 선택
3. Branch **main**, Folder **/(root)** 선택 후 저장
4. 배포가 완료되면 `https://luckybridge.github.io/interview/` 주소에서 사용

## 링크 변경
`index.html` 파일 아래쪽의 `const links = [...]` 항목에서 23개 Gemini Gem URL을 순서대로 관리할 수 있습니다. 현재 제공된 링크 자료에는 인물명이나 주제 정보가 없어 카드 제목은 번호로 표시합니다.

## 수업 활용 시 유의 사항
- 인터뷰 링크는 외부 Gemini 서비스로 이동합니다. 로그인, 교육용 계정 정책, 미성년자 접근 권한 및 Gem 공유 설정에 따라 접속이 제한될 수 있습니다.
- 방문 기록은 링크를 눌렀는지를 뜻하며 실제 인터뷰 완료 여부를 의미하지 않습니다.
- AI 응답을 그대로 토의의 정답으로 사용하지 않고, 사실과 의견을 구분해 재검토하도록 지도합니다.
- 정적인 사이트이므로 서버·데이터베이스·학생 로그인 기능은 없습니다.
