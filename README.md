# 우리 동네 토의 탐구실

초등학교 5학년 국어 「의견을 조정해요」에서 보행 안전과 늦은 시각 소음 문제를 탐구하는 정적 웹사이트입니다. 가상 시민과의 인터뷰, 조사 자료, 개인 의견 마련과 모둠 토의를 연결합니다.

## 수업 흐름

| 차시 | 활동 |
|---|---|
| 9~10차시 | 다양한 입장과 자료 살펴보기, 문제 정의, 아이디어 발산, 개인 의견과 근거 마련 |
| 11~12차시 | 의견 나누기, 함께 검토할 문제 확인, 기준에 따른 의견 모으기, 공동 제안 결정, 전체 공유 |
| 13차시 | 학급 공동 의견 비교·조정과 결정 |
| 14차시 | 공동 제안서 작성과 성찰 |

## 페이지

- `index.html`: 보행 안전 탐구·조사 자료, 가상 인물 24명 인터뷰, 소음 탐구·가상 시민 32명 인터뷰, 공통 학습 자료. 인터뷰는 Google Gemini Gem에서 열립니다.
- `workroom.html#personal`: 9~10차시 개인 활동 기록. 가상 인터뷰, 실제 주변 사람의 입장, 직접 경험, 확인한 자료를 구분합니다.
- `workroom.html#group`: 11~12차시 모둠 활동 기록. 각 모둠원 칸에서 개인 JSON 기록을 불러와 다시 입력하는 수고를 줄일 수 있습니다. 3~5명 기록, 공통 문제, 검토 기준, 의견별 좋은 점·걱정·질문·보완점, 최종 제안과 조정 과정을 남깁니다.
- `materials/personal-9-10.pdf`, `materials/group-11-12.pdf`: 각각 A4 한 쪽 인쇄용 활동지. 개인은 학생마다 한 장, 모둠은 모둠마다 한 장을 사용합니다.

개인 기본 화면은 네 단계, 모둠은 세 단계로 간단히 기록합니다. 추가 항목과 이전 상세 기록은 ‘더 기록하기’에서 확인합니다. 상단의 기록만·탐구만·함께 보기로 탐구를 오가며 적을 수 있고 넓은 화면에서는 좌우로 함께 표시합니다.

학생이 의견을 만들고 조정하도록 돕는 기록 도구입니다. 제안 순위를 자동으로 매기거나 해결책을 생성하지 않습니다.

## 실행과 검증

보행자 안전 홈은 개인활동과 함께 보기가 선택된 활동 공간으로 열립니다. 탐구 자료만 별도로 보려면 `index.html?explore=1#home`을 사용합니다. 개인활동은 1~3단계에 큰 자유 입력란을 하나씩, 4단계에 의견과 이유·근거 입력란을 제공합니다. 기존 상세 기록과 JSON 파일은 v4로 이어 쓸 수 있으며 이전 상세 항목은 읽기 전용으로 확인합니다.

추가 패키지 설치나 빌드 과정이 없습니다. 프로젝트 폴더에서 HTTP 서버로 실행합니다.

```sh
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173/`을 엽니다. 모듈을 사용하는 기록 페이지는 파일을 직접 여는 대신 HTTP 서버를 이용합니다.

상태·파일 검증·텍스트 출력·저장 실패 처리는 Node 기본 테스트로 확인합니다.

```sh
node --test --experimental-test-coverage tests/*.test.mjs
```

## 저장과 기기 이동

개인 기록과 모둠 기록은 서로 다른 버전별 키로 이 기기와 브라우저의 로컬 저장소에 자동 저장됩니다. 저장 완료와 실패를 화면에 표시합니다. 서버 전송이나 기기 간 자동 공유는 없습니다. 친구의 기록을 열려면 기록 파일을 전달받아 해당 활동에서 불러오세요.

- JSON 기록 파일: 이어 쓰기와 백업. 앱·버전·활동 종류·필드·문자 수·모둠원 수를 검사합니다. 2MB 이하만 허용합니다. 불러오기 전에 현재 내용을 바꿀지 확인합니다.
- 글 파일과 복사: 문서에 옮겨 쓰거나 함께 읽는 용도입니다. 복사가 제한되면 선택할 수 있는 글을 화면에 표시합니다.
- 작성한 기록 인쇄: 현재 선택한 개인 또는 모둠의 기록을 간결한 글로 인쇄합니다. 긴 입력은 줄바꿈되어 전체 내용이 나타납니다. 빈 활동지가 필요하면 PDF를 내려받습니다.
- 저장 불가·손상 기록·다른 창의 수정 감지: 자동 저장을 멈추고 파일 백업 또는 저장된 기록 다시 읽기를 안내합니다. 현재 내용으로 저장을 다시 시작할 때 확인을 받습니다.

모둠원별 개인 기록 불러오기는 해당 모둠원의 이름·문제·제안·이유·근거와 출처를 옮깁니다. 바꾸기 전 확인하며 이 의견의 검토 기록은 비우고, 모든 모둠원의 최종 확인 표시를 해제합니다. 다른 모둠원의 글과 공동 제안은 유지합니다. 전체 모둠 기록 불러오기는 계속 모둠 파일만 받습니다. 합쳐진 근거·출처가 한 칸의 8000자를 넘으면 원본을 자르지 않고 불러오기를 중단합니다.

공용 기기에서는 번호나 별칭을 사용하고, 수업이 끝나면 파일로 보관한 뒤 교사의 공용 기기 관리 절차를 따르세요. 이 사이트는 학생 로그인이나 중앙 수집 기능을 제공하지 않습니다.

## 자료와 AI 사용

가상 시민의 이야기는 실제 지역 현황의 증거가 아닙니다. 조사 자료는 제목·발행 기관 또는 주소·확인 날짜·대상 지역과 시기를 기록하고, 제안의 근거와 연결합니다. 외부 Gemini·NotebookLM 자료는 계정과 공유 권한에 따라 접근이 제한될 수 있습니다. 방문 표시는 링크를 눌렀다는 뜻이며 인터뷰 완료 여부를 증명하지 않습니다.

Gem 링크는 `index.html`의 `links`, 보행 인물 `.walk-card`에서 관리합니다. 소음 인물 정보는 `people`에 있습니다. 프로필 이미지는 `profiles/01.webp`~`profiles/23.webp`이며 이후 번호는 대체 표시를 사용합니다.

## 배포와 로컬 수업 문서

GitHub Pages는 `main` 브랜치의 루트 폴더를 배포 대상으로 사용할 수 있습니다. 현재 수정본은 로컬 검토용이며 이 작업에서 푸시하거나 배포하지 않았습니다.

상위 워크스페이스의 `../teaching/`에는 지도안과 활동지의 편집용 문서가 함께 관리됩니다. 상위 폴더는 이 Git 저장소나 GitHub Pages 배포에 포함되지 않으며, 웹 배포용 PDF만 이 저장소의 `materials/`에 복사합니다.

## 활동지 다운로드

홈페이지의 **활동지 다운로드** 탭 또는 `index.html#downloads`에서 개인 의견 마련(9~10차시)과 모둠 토의(11~12차시) 활동지를 받습니다. 각각 A4 한 쪽이며 인쇄용 PDF와 편집용 DOCX를 제공합니다. 최신 원본은 상위 teaching/02-활동지이며 scripts/sync_materials.py로 웹 materials/에 동기화합니다.

다운로드 탭에는 전체 지도안·본시 지도안(11~12차시)·개인 활동지·모둠 활동지의 HWPX가 있습니다. 지도안은 2026년 10월 28일 제공된 수정본 HWPX·PDF를 원본 그대로 사용합니다. 전체 지도안 PDF는 12쪽, 본시 지도안 PDF는 6쪽이며, 개인·모둠 활동지는 각각 한 쪽입니다.

## 의견·근거 이미지 제출

개인활동은 이미지를 생성·저장한 뒤 자기 모둠(1~6)의 패들렛을 선택해 PNG를 게시합니다. 모둠활동은 최종 의견 이미지를 학급 패들렛에 게시합니다. 링크를 여는 것만으로 제출되지 않으며 학생이 이미지를 직접 첨부해야 합니다. Google Drive는 ‘다른 제출 방법’에 있습니다.

이미지는 1920×1080이며 내용에 맞춰 큰 글씨로 조정합니다. 단어 사이에서 우선 줄을 바꾸며 한 줄보다 긴 단어만 나눕니다. 너무 긴 글은 잘라내지 않고 내용을 줄이도록 안내합니다.

개인활동에는 우리 모둠과 이름, 모둠활동에는 우리 모둠을 입력합니다. 이미지 파일명은 `3모둠_이름_개인의견-근거.png` 또는 `3모둠_모둠의견-근거.png`로 저장합니다. 이미지 생성 전에 필수 정보를 확인하며 이전 v1~v3 기록은 내용을 유지해 v4로 읽습니다.
