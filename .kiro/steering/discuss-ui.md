# 놀토의 화면 작업

knoldiscuss 폴더의 화면 파일을 다룬다. 고치기 전에 이 폴더의 `DESIGN.md`와 `.agents/skills/discuss-ui-change/SKILL.md`를 읽고 따른다.

빠뜨리기 쉬운 것:
- 기록 저장 키, 기록 파일 형식, 필드는 그대로 둔다. 바꿔야 하면 `.agents/skills/discuss-records-compat/SKILL.md`.
- 공개 주소(`#personal`, `#group`, 자료 경로 해시, `?explore=1`, `?embed=1`, `?view=both`)와 페이지 사이 메시지를 지킨다(`docs/architecture.md`).
- 외부 링크를 지우지 않는다. 고친 파일을 부르는 `?v=`를 모두 올린다.
- 끝내기 전에 `.agents/skills/discuss-verify/SKILL.md`.
