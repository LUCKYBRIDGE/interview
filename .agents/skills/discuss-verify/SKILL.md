# 놀토의 검증

경로는 knoldiscuss 저장소 루트 기준이다.

## 항상

- `npm test`: 단위 테스트와 사이트 무결성(로컬 참조, `?v=` 일치, 외부 링크 기준선, 화면 부채 지표).
- `npm run check`: 지침, 스킬, 스티어링, `docs/`를 고쳤을 때.
- `git diff --check`와 `git status`: 의도하지 않은 파일(`.DS_Store`, `.qa/`)이 없는지.

## 화면을 바꿨을 때 (ego-browser)

- 사용자의 실제 기록과 섞이지 않게 다른 포트로 띄운다: `node scripts/serve.mjs 4191`. 기록장은 페이지를 떠날 때 빈 기록도 저장하므로 검증 방문만으로 저장 키가 생긴다.
- 주 기기는 태블릿과 PC다(`docs/decisions/0002-target-devices.md`). 크기: 세로 태블릿 820×1180(또는 768×1024), 가로 태블릿 1024×768(또는 1180×820), PC 1366×768과 1920×1080. 태블릿은 `Emulation.setDeviceMetricsOverride`에 `mobile: true`를 주고 `Emulation.setTouchEmulationEnabled`를 켜서 본다. 휴대폰 390×844는 가로 넘침과 겹침만 본다.
- 크기마다 가로 넘침이 없는지, 첫 화면에 지금 할 일과 주 버튼, 첫 입력란이 보이는지 본다.
- 키보드만으로: Tab 순서, 초점 표시, 탭과 접기, Esc.
- 기록장: 입력, 자동 저장 표시, 새로고침 뒤 복원, 개인과 모둠 전환 뒤 보존, 기록 파일 내려받기와 불러오기(취소하면 그대로), 다른 창 수정 감지, 의견 이미지 만들기와 저장, 패들렛 링크.
- 자료: 탭 이동과 주소 해시, `?explore=1` 단독 보기, 기록장 패널 안에서 활동 링크.
- 소음 주제를 누르면 알림창이 뜰 수 있다(1단계 전). 스크립트에서 대화상자를 처리한다.
- 인쇄 미리보기: 작성한 기록이 A4로 나오고 입력 양식과 자료 패널이 빠지는지.
- 전후 캡처를 `.qa/<날짜>-<작업>/`에 남기고 바뀐 부분만 의도대로인지 본다.
- 끝나면 검증 포트에 생긴 기록 중 비어 있음을 확인한 것만 지우고 TaskSpace를 닫는다. 사용자의 탭, 로그인, 다른 저장 값을 지우지 않는다.
- ego-browser는 Chromium이다. 아이패드 Safari 동작(파일 저장, 화면 키보드)은 실제 기기로 본 경우에만 확인했다고 쓴다.

## 보고와 기록

- 확인한 것과 확인하지 못한 것(실제 태블릿, 학생 계정의 Gemini, 실제 인쇄, 공개 사이트)을 나눠 쓴다.
- `PROJECT_STATUS.md` 맨 위에 날짜 항목을, `CHECKLIST.md`에 확인 항목을 남긴다.
